# StrawberrAI

**En tydlig webbidentitet för praktiska AI-idéer**

En responsiv statisk webbplats med en sammanhållen visuell identitet. Ett kompletterande arbetsprov i att göra ett tekniskt ämne lättare att förstå.

## Behov

Tekniska möjligheter behöver en begriplig ingång, tydlig struktur och ett visuellt uttryck som håller ihop på både dator och mobil.

## Lösning

HTML, CSS och webbmedia bygger en publicerad presentationssida. Den är ett gränssnitts-/kommunikationsprov, inte ett bevis för en färdig AI-tjänst i bakgrunden.

## Min insats

Koncept och visuell riktning med AI-assisterad implementation och webbläsargranskning.

## Verifiering

Startsidan inspekterades i 1280 respektive 390 pixlars viewport 2026-10-27. Alla sju bilder laddade och ingen horisontell överrinning observerades i dessa vyer.

## Avgränsning

Ingen AI-backend eller meddelandeleverans verifierades. Webbplatsens marknadsbudskap är inte en uppmätt effekt eller dokumenterad kundleverans.

## Förenklat flöde

```text
Innehåll → Visuell identitet → Responsiv HTML / CSS → Publicerad sida
```

**Teknik:** HTML, CSS, Responsiv design, GitHub Pages.

**Status:** Publik statisk webbplats.
